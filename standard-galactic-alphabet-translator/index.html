What is the Standard Galactic Alphabet?

The Standard Galactic Alphabet is a set of 26 symbols that replace the letters A to Z. This Standard Galactic Alphabet translator makes the swap in either direction. It does not change English into another language. The spelling, word order and meaning stay the same. Only the letters look different.

Tom Hall created the alphabet for the Commander Keen games. It later became familiar to Minecraft players as the script in the enchanting table. A short word can look mysterious, but anyone with the alphabet key can read it. This makes it fun for puzzles. It does not make a message secure.

How to read the enchanting table language

Look at one symbol at a time. Find its English letter in the key, write that letter down, then move to the next symbol. Keep the spaces where they are. For example, the four symbols for l, i, g and h, followed by t, spell light. That word appears in the enchanting table word list.

If you have copied glyph text, paste it into the box above. The tool detects most common glyph characters and switches to English. You can also choose the direction yourself. This helps when the text uses a keyboard shortcut that looks like ordinary punctuation.

To read a screenshot, open Decode with glyph keys. Tap the symbols you see in order. The keyboard adds each one without opening your phone’s typing keyboard. The English result changes with every tap. Use Space between words and Backspace to correct a tap.

How to write, copy and paste it

Type a name or a short message. The drawn symbols appear at once. Copy saves the look-alike text to your clipboard. You can paste it into a chat, profile or invitation. The copied characters are real text, so their shape depends on the fonts available on the receiving device.

P, T and X need more than one character to make a useful look-alike. A text app may space these parts differently. Some devices may show a missing-character box. For a consistent appearance, save a PNG instead. The image uses the same drawn symbols you see in the large result.

Does the enchanting table text mean anything?

The table displays random words. Reading those words does not tell you which enchantment you will receive. See all 62 enchanting table words for the list and the Java-only entries.

Does the Standard Galactic Alphabet have numbers?

The original alphabet has no numerals. By default, this tool writes numbers as English words before converting them. For example, 23 becomes twenty-three and 1,234 becomes one thousand two hundred thirty-four. Turn off Spell numbers as words to leave digits unchanged.

A number with a leading zero is read digit by digit, so 007 becomes zero zero seven. Numbers longer than six digits also use separate digit names. Decimal points remain punctuation. This avoids guessing whether a dot is part of a number or a sentence.

Frequently asked questions

What language is the Minecraft enchanting table written in?

It uses the Standard Galactic Alphabet. Each symbol stands for an English letter. Reading the symbols reveals English words.

How do I translate enchanting table text from a screenshot?

Open Decode with glyph keys and tap the symbols in the screenshot. The English result appears as you tap. This tool does not upload or scan images.

Why do some letters copy as two characters, or show as boxes?

The copied text uses Unicode look-alikes. P, T and X use several characters. Font support varies, especially for K and L. We have not verified every phone. Save a PNG if you need consistent letter shapes.

Is the Standard Galactic Alphabet in Unicode?

It does not have its own standard Unicode alphabet. Copy-and-paste tools use similar-looking characters from other scripts and symbols.

Is there a Standard Galactic Alphabet font?

Fonts exist, but this tool does not offer a font file. Use the copyable text or save an image of our drawn glyphs instead.

Is the Standard Galactic Alphabet from Star Wars?

No. It comes from Commander Keen. The Star Wars writing system commonly called Aurebesh is a different alphabet.

Is my text sent anywhere?

No. Translation, images and worksheets are made in your browser. Only your theme choice is saved on this device. A share link contains the text, so anyone you share it with can read it.
