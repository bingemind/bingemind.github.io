Three ways to use the sheet

The answer key pairs each glyph with its letter. Keep it beside a code-breaking activity. The practice sheet leaves a blank under each glyph, so a learner can fill in the letter from memory.

The secret message worksheet turns your own short clue into symbols and adds writing space below each word. The key sits underneath a fold line. Fold it back before handing out the puzzle, then let readers reveal it when they need a hint.

Printing on Letter or A4

Choose your version, then select Print chart. The layout fits both paper sizes. Use portrait orientation and the default scale. You can also choose Save as PDF in your browser’s print dialog. Turn off browser headers and footers if you want a cleaner sheet.

These are our own clean drawings of the alphabet. There are 26 letters, with the same glyph for upper- and lowercase text. Numbers use English words. For longer messages and PNG images, use the Standard Galactic Alphabet translator.
