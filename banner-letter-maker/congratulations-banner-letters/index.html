    Length of the finished banner

    Each portrait Letter page is 8.5 inches wide. Fifteen pages in a row measure about 10.6 feet. On A4 paper the row is about 10.3 feet. Landscape pages are wider, so the same message is about 13.75 feet long on Letter paper.

    Ideas

    • Use school colors for a graduation. Pick one color for the whole banner.
    • Use Rainbow for a bright, mixed look.
    • Add the graduate name on a second row of pages.

    Print at actual size

    In the print dialog, choose 100% or Actual size. Do not choose Fit to page. That setting shrinks the page, and the punch marks move.

    Questions

    How many pages is Congratulations?

    CONGRATULATIONS is 15 letters, so it uses 15 pages. CONGRATS is 9 letters. A message with an exclamation mark adds one page.

    How long is the banner?

    On portrait Letter pages it is about 10.6 feet. Check your wall before you print.

    Can I print one row on two lines?

    Yes. Make two PDFs, one for each line, and hang them one above the other.
