    What DPI means

    DPI stands for dots per inch. It tells a printer how many pixels of the image to place in one inch of paper. A 3000 by 2000 pixel photo at 300 DPI prints at 10 by 6.7 inches. The same photo at 150 DPI prints at 20 by 13.3 inches. The pixels did not change. Only the printed size did.

    Why print shops ask for 300 DPI

    At 300 DPI, the dots are so small that the eye sees smooth lines and sharp text. Below about 150 DPI, edges start to look soft or blocky. Print shops, photo labs and print-on-demand sites such as Etsy printables and book printers use 300 DPI as a safe standard. Large posters viewed from far away can use less.

    DPI is not the same as pixels

    Pixels are the real detail in a picture. DPI is only a label that says how big to print those pixels. A file can say 72 DPI or 300 DPI and hold exactly the same picture. Screens ignore the DPI value. Print software and layout programs read it to set the size on the page.

    This is why a file that says 72 DPI is often rejected by a print service. The label is wrong for print, even if the picture is fine. Changing the label fixes that without any loss.

    When changing DPI is not enough

    Changing the DPI label does not add detail. If you need an 8 by 10 inch print at 300 DPI, the image must be at least 2400 by 3000 pixels. A small web image of 800 by 600 pixels will become 2.7 by 2 inches at 300 DPI. If you force it to print larger, it will look soft.

    Do the math before you print: pixels divided by DPI gives inches. The tool shows this for you in inches and centimeters. If the print size is too small, you need a larger original. Upscaling programs can add pixels, but they guess the new detail and can change the look of the image.

    DPI and PPI

    You may also see PPI, which means pixels per inch. For image files the two terms mean the same thing in daily use. Photo apps say PPI. Print shops say DPI. Printers also use the word DPI for ink dots, which is a different number. For your image file, the value in the header is the one that counts.

    Which DPI to pick

    • 72: screens and web pages. Printers do not use it.
    • 96: Windows screens and some office programs.
    • 150: large posters and banners seen from a distance.
    • 300: photos, flyers, cards, books and most print shops.
    • 600: fine line art, scans and small text.

    Frequently asked questions

    Does changing DPI reduce image quality?

    No. The tool edits only the DPI value in the file header. The pixel data is not decoded, resized or compressed again, so the image is identical.

    Will a 72 DPI image look better at 300 DPI?

    No. DPI does not add detail. It changes the printed size. A 3000 by 2000 pixel image prints at 10 by 6.7 inches at 300 DPI, whatever the old DPI value was.

    Are my images uploaded to a server?

    No. Everything runs in your browser. Your images never leave your device, and nothing is stored.

    Which file types does it support?

    JPEG (.jpg, .jpeg) and PNG (.png). A WebP file is also accepted and is saved as a PNG with the same pixels, because PNG can store a DPI value. HEIC, TIFF and BMP are not supported yet.

    Can I paste an image instead of choosing a file?

    Yes. Copy an image or a screenshot, click the page, and press Ctrl+V (Cmd+V on a Mac). It is added to the list.

    Can I change many files at once?

    Yes. Add as many files as you like, choose the DPI, and download each file or one zip with all of them.

    What DPI should I use for printing?

    Use 300 DPI for photos, flyers and most print jobs. Use 150 DPI for large prints seen from a distance. Always follow the rule of your print shop if it gives one.

    How do I check the new DPI?

    On a Mac, open the file in Preview and choose Tools, then Show Inspector. On Windows, right-click the file, open Properties, then the Details tab. You can also add the file back to this tool to read its DPI.

    Why does the print size change when I change DPI?

    Print size is pixels divided by DPI. When DPI goes up, the same pixels cover fewer inches. That is why 300 DPI gives a smaller print than 72 DPI for the same file.
