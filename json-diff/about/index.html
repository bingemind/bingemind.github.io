About

JSON Diff Checker is a free tool that compares two JSON documents. It lists every change with its path, the old value and the new value. It ignores key order and spacing, so you only see real changes.

Who it is for

Developers, testers, data analysts and anyone who works with APIs, config files or exports. It works on a phone or a computer.

How to use it

Paste the first JSON into Original and the second into Changed. The result updates while you type. Use Options to match array items by a key such as id, to ignore fields like updatedAt, and to set rules for numbers and text.

How it works

The comparison runs in your browser, in a background worker. Numbers are compared by exact value, so large ids are never rounded. The page does not send your JSON to a server. We do not ask you to create an account. The tool saves your option choices on your own device. It does not save your documents.
