README.md to a clean PDF

README to PDF

A README is written for developers, but you often need to hand it to someone who does not use Git. A manager, a client, or an auditor wants a file they can open. Here is the fast way: open the README, check the preview, save a PDF.

Opens your print screen. Choose Save as PDF.

Preview (what the PDF will look like)

The button opens your browser print dialog. Choose Save as PDF as the destination. For a clean page, turn off "Headers and footers". The file is named after your first heading. Everything stays on your device.

Saving a PDF on a phone or tablet

iPhone and iPad (Safari)

  1. Press Download PDF.
  2. On the page preview, spread two fingers apart. The PDF opens full screen.
  3. Tap the Share button, then Save to Files.

Android (Chrome)

  1. Press Download PDF.
  2. At the top of the print screen, set Destination to Save as PDF.
  3. Tap the round PDF button and choose where to save.

Two settings for a clean PDF

Your browser opens its print window next. In that window:

  1. Set Destination to Save as PDF.
  2. Turn off Headers and footers.

Steps for a README

  1. Press Open .md file and choose README.md. You can also drag the file onto the editor.
  2. Pick the Technical theme. It uses tighter spacing and a code style close to the one on GitHub.
  3. Press Insert contents if the README is long and has no table of contents.
  4. Turn on page numbers, then press Download PDF and choose Save as PDF.

What READMEs use, and what happens to it

  • Code blocks keep their colors. Name the language after the three backticks.
  • Tables print with borders. The header row repeats when a table runs onto the next page.
  • Task lists print as open and checked boxes.
  • Alert blocks such as NOTE and WARNING print with a colored bar.
  • Badges and images show if their address allows hotlinking. A badge that fails to load shows its alt text instead.
  • HTML such as details and kbd works. Unsafe HTML is removed.

Relative links and images

A README often points to files in the repository, such as ./docs/setup.md or ./img/logo.png. A browser has no repository, so those paths cannot load. Replace them with full web addresses before you convert. A raw GitHub address works for images.

Links to headings inside the README work. [Install](#install) jumps to the heading named Install, in the preview and in the PDF.

Long code lines

Long lines wrap inside the code block instead of running off the page. Short blocks stay on one page. A block of more than about 38 lines is allowed to split across pages.

Questions

Can I convert a README from a private repository?

Yes. Copy the text from your own checkout and paste it here. Nothing is uploaded, so the content stays private.

Why is my badge missing?

The badge image did not load. The service that hosts it may block hotlinking, or your network may block it. The rest of the page is not affected.

Does it keep the front matter?

By default it removes the front matter block. Turn on "Print as a table" to show it as a small table at the top.
